# Class Space

Vercel-ready Next.js dashboard for a modern class website.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Upload this project to GitHub.
2. Import the repository into Vercel.
3. Vercel detects Next.js automatically.
4. Deploy.

## Notes

This version is a front-end prototype. Data in `app/page.tsx` is mock data.
For production, connect it to a database/API such as Supabase, Firebase, or a custom backend.
